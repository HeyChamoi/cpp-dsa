# Basics

This folder contains the C++ fundamentals required before diving into Data Structures & Algorithms.

It is **not** intended to cover first-time programming concepts. Since I already have prior experience with C, Java, and Python, introductory topics such as Input/Output, Data Types, and Operators have been omitted to avoid unnecessary repetition.
The focus of this folder is on the C++ concepts and problem-solving fundamentals that form the foundation for learning Data Structures & Algorithms.
